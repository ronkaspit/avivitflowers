# אביבית בוטיק פרחים · אתר סטטי

אתר סטטי (HTML בלבד, בלי build). Vercel יזהה אותו אוטומטית.

## מבנה
- `index.html` — דף הבית
- `workshops.html` — סדנאות
- `about.html` — קצת עליי
- `assets/` — תמונות הבוטיק
- `support.js`, `image-slot.js` — סקריפטים נדרשים
- `robots.txt`, `sitemap.xml`, `llms.txt` — SEO/GEO
- `vercel.json` — כתובות נקיות (/about, /workshops) וקאשינג

## פריסה
1. העלו את כל תוכן התיקייה הזו לשורש הריפו `ronkaspit/avivitflowers` (branch: `main`).
2. ב‑Vercel: Framework Preset = **Other**, Build Command ריק, Output Directory ריק.
3. כל push ל‑`main` יפרוס אוטומטית.

טלפון/וואטסאפ באתר: 050-7915259

## SEO: פעולות ידניות שנותרו
1. Google Search Console: לאמת את הדומיין ולשלוח את https://www.avivit-flowers.com/sitemap.xml.
2. Google Business Profile: לפתוח פרופיל "אביבית בוטיק פרחים" באשדוד, לקשר לאתר ולהעלות תמונות.
3. לבקש מלקוחות ביקורות בגוגל (משפיע הכי חזק על חיפוש מקומי).
4. Bing Webmaster Tools: לייבא מ-Search Console (חינם; משפיע על ChatGPT/Copilot).
